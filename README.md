# Aula digital -- Projecte Intermodular SMX

Transformacio de una aula tradicional en una aula digital: mobiliari especific per a ordinadors, armari rack 
amb switch i router, rosetes RJ45 a la paret per a una xarxa de area local, eixida a internet,pissarra digital
i impressora en xarxa.
